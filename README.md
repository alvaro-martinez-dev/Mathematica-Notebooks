# Mathematica Notebooks

A collection of Wolfram Mathematica notebooks I wrote during my BSc in Physics at the Universitat de València. They cover data analysis for lab reports, numerical calculations and graded assignments across several courses.

Each notebook (`.nb`) comes with a PDF export, so you can read the results directly on GitHub without having Mathematica installed.

## Contents

| Folder | Course | Topics |
|---|---|---|
| `ATROFÍSICA` | Astrophysics | HR diagram, polytropic stellar models, binary stars |
| `FÍSICA ESTADÍSTICA` | Statistical Physics | Assignments A2 and A3 |
| `LAB CUÁNTICA` | Quantum Physics Lab | Photoelectric effect, electron diffraction, X-rays, incandescent filament, Stefan–Boltzmann law |
| `LAB MECÁNICA` | Mechanics Lab | Lab sessions P1–P8 |
| `OPTICA` | Optics | Interference |

## How to open the notebooks

- **PDF versions**: click any `.pdf` file to view it directly in the browser.
- **Notebooks (`.nb`)**: open them with [Wolfram Mathematica](https://www.wolfram.com/mathematica/) or with the free [Wolfram Player](https://www.wolfram.com/player/) (read-only).

## Notes

- The notebooks are written in Spanish.
- They were made as coursework, so they reflect what was required for each assignment rather than polished, general-purpose code.
